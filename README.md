# New Forest Autocentre

Responsive marketing website for New Forest Autocentre Ltd in New Milton.

The site is deliberately dependency-free. Open `index.html` through any static web server or deploy the repository directly with GitHub Pages.

The booking and enquiry forms prepare an email in the visitor's email application. This keeps the static site deployable without a paid form backend. Replace this with a server-side form endpoint before launch if direct in-page submission is required.
